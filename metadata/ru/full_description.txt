Escapepod - это проигрыватель передач подкастов с минималистским подходом, который может не понравиться всем. Приложение имеет только один экран. Элементы управления воспроизведением и список подкастов с пятью последними выпускам. У Escapepod нет функции обнаружения подкастов. Он предлагает только очень простой параметр поиска и открывает ссылки на подкасты RSS, когда вы нажимаете на них в веб-браузере.


ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

У ESCAPEPOD ЕСТЬ ОЧЕРЕДЬ ВОСПРОИЗВЕДЕНИЯ?
Escape Pod обладает простой следующей функцией. Нажмите «Воспроизвести» в выпуске, одновременно слушая другой. Вам будет предоставлена возможность добавить его в следующий слот.

КАКОВЫ НАСТРОЙКИ ПО УМОЛЧАНИЮ?
- Автообновление не загружает файлы по сотовой сети
- Escapepod по умолчанию сохраняет только два выпуска

МОЖЕТ ЛИ ESCAPEPOD ХРАНИТЬ БОЛЬШЕ ДВУХ ВЫПУСКОВ?
Escapepod пытается уменьшить количество выпусков, которые он хранит. Вот правила для этого:
- Escapepod хранит последние два выпуска.
- Выпуски, которые были запущены, или которые были скачаны вручную, тоже хранятся.
- Максимальное количество доступных (и сохраненных) выпусков - пять

ПОДДЕРЖИВАЕТ ЛИ ESCAPEPOD OPML?
Вы можете импортировать список подкастов, используя формат обмена OPML, используя соответствующий параметр в настройках приложения. Текущую коллекцию подкастов также можно экспортировать через настройки. Кроме того, Escapepod хранит актуальный файл OPML в папке /Android/data/org.y20k.escapepod/files/collection/.

ОТКУДА БЕРУТСЯ РЕЗУЛЬТАТЫ ПОИСКА ПОДКАСТОВ?
Escapepod по умолчанию выполняет поиск в сетевой базе данных Podcastindex.org (https://podcastindex.org/) - или, если вы переключите соответствующий параметр в настройках, сетевую базу данных gpodder.net (https://gpodder.net/directory/).
